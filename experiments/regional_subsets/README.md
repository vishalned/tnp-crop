# Regional subsets

**Question / setup.** Pretraining on the north-west, central-east or southern countries (or FR/BE/DK) of the densified table (old soil) only, benchmarked on all 18.

**Configs.** `sanity_regions_nw`, `_ce`, `_south`, `_frbedk` (`data.countries`)

**Figures and files.** `figures/overview.png` (mean and weighted mean).

**Result.** No region is responsible for the gain: the subsets are within 0.007 NRMSE of each other.

Index of all experiments: `docs/experiments.md`.
